Convert 3D models into ASCII art! Includes support for colored/uncolored renders and setting up your scene in the viewport using models, lights and colors. You can also move and rotate models.

PS: You need to have blender installed and export .obj files from there, or search online for .obj files (idk if other 3D modelling platforms layout their .obj file exports differently, so do look for indications that the model was made in blender to be safe). Textures aren't carried over and to see any model within the scene you'll need to add a light by right-clicking the scene view.
